Antibody discovery · GV20 Therapeutics2024

Which antibodies might recognize the targets that matter?

A patient’s immune repertoire contains many possible antibodies, often seen only as fragmented receptor sequences. PhialBCR brings together DeepTRUST’s patient-level sequence representations, antibody–target affinity prediction, and CloudMD’s reproducible molecular-dynamics simulations. The shared goal is to learn from incomplete repertoire evidence, prioritize promising antibody–target pairs, and explore the behavior of antibodies and their complexes.

Talk Related paper

Talk by Sherlock Hu · Paper by Li et al., Cell (2024)

Project & output details

DeepTRUST. Axial attention over a patient’s BCR multiple-sequence alignment supports sequence imputation and compact representations. Cancer-type and isotype prediction provide training tasks.

PhialBCR. Multitask learning connects these representations to cancer-type and antibody–target affinity prediction, using public and in-vitro training data.

CloudMD. Containerized GROMACS workflows run antibody and antibody–antigen simulations from protein structures across cloud, GPU, and distributed computing environments.

Genotype imputation · Chinese Academy of Sciences2021

What can the patterns we observe tell us about the gaps?

Genetic datasets often have gaps: not every variant is observed reliably. DNA Imputation explores how patterns across nearby variants can help recover missing genotypes. Using sparse convolutional denoising autoencoders, the project learns to reconstruct masked alleles from their surrounding context, with the aim of providing more informative inputs for downstream genetic analyses.

Approach & scope

Reconstruction. A reference-free, one-dimensional convolutional encoder–decoder uses correlations between variants, including linkage disequilibrium, to infer missing allele information.

Training. The SCDA baseline learns from randomly masked alleles using cross-entropy reconstruction, dropout, and an L1 sparsity constraint. The input is an aligned vector of 28,220 positions with placeholders for missing values and padding.

Directions explored. The 2021 study considered block masking, refined sparsity, transfer learning, recurrent models, and the use of reference data as possible extensions.

Interactive RNA-seq · University of Washington2020

Can a complex RNA-seq analysis become an interactive experiment?

RNA-seq analysis can be slowed by complex software setups and long alignment times. BioDepot Workflow Builder brings tools together as reusable, containerized widgets in a visual workflow. This 2020 work connects that graphical interface with serverless RNA-seq computing, enabling researchers to adjust alignment parameters, rerun analyses, and explore results interactively without managing the underlying cloud infrastructure.

Serverless cloud computing · University of Washington2019

Should a biological question have to wait for a bigger computer?

Comparing protein sequences helps reveal shared functions, but the number of comparisons grows rapidly as collections expand. Long runtimes and the burden of managing computing infrastructure can put large analyses out of reach. This project explores serverless parallel computing to make large-scale sequence comparison faster and more accessible to researchers.
